🎓 Handwritten Mathematical Formula Recognition & Solver System

An End-to-End Artificial Intelligence & Computer Vision Project designed for the Software Innovation Competition (SIC). Combines PyTorch Encoder-Decoder Neural Transformers, OpenCV Image Segmentation, SymPy Symbolic Solving, and Gemini AI.

Neural Network Architecture

Uses a hybrid CRNN + Transformer Decoder model. The vision encoder extracts multi-scale spatial feature maps from raw handwritten notebook images, projected via 1x1 convolution ($d_{model}=256$) into a 4-layer Transformer Decoder with 8 Multi-Head Attention heads.

EfficientNet-B0 Vision Backbone Sinusoidal Positional Encoding 4-Layer Transformer Decoder 241 Token LaTeX Vocab

Preprocessing & OpenCV Segmentation

Features an advanced image pipeline using Adaptive Gaussian Thresholding and Horizontal Projection Profiling (HPP) to isolate dark ink strokes from notebook ruled lines and segment multi-line stacked equations top-to-bottom.

Otsu Binarization Horizontal Projection Profiling Tensor Canvas 128x512 Multi-Line Stacked LaTeX

Mathematical Solver & Plotter

Integrates SymPy Symbolic Engine to calculate exact algebraic roots, indefinite integrals, and summations, paired with Matplotlib for real-time dark-mode function curve plotting ($x \in [-10, 10]$).

SymPy Symbolic Math Matplotlib Curve Plotting Exact Algebraic Roots Calculus & Summations

Gemini AI Pedagogical Assistant

Powered by gemini-2.5-flash via the official google-genai SDK to generate step-by-step mathematical intuition, real-world application breakdowns, and conceptual explanations for student learning.

google-genai SDK gemini-2.5-flash Model Step-by-Step Derivations Real-World Intuition

Cloud Infrastructure & Deployment

Deployed as a high-performance decoupled architecture: Vercel Edge Network hosts the responsive glassmorphism frontend, while FastAPI + Ngrok HTTPS Tunnel powers GPU/CPU neural inference.
